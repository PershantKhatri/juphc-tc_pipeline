# Tekton Tasks & CI/CD Pipeline Project

This repository contains Tekton task definitions and configuration files for setting up automated workflows, including Node.js package installation and Jasmine unit testing.

## 📂 Project Structure

- `tasks.yaml`: Defines custom Tekton tasks for running `npm install` and `npx jasmine` tests.
- `02-dockerfile`: Dockerfile configuration for containerizing the application using Nginx.

## 🚀 Technologies Used
- Tekton Pipelines
- Docker & Nginx
- Node.js & Jasmine Unit Testing
- GitHub
